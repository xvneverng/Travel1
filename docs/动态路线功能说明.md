# 动态路线功能实现说明

## 🎯 功能概述

将原本写死的南京旅游路线改为用户可以自定义输入的动态路线功能。用户可以通过界面输入起点、途经点和终点，系统会实时生成对应的地图和分段路线。

## 🔧 实现思路

### 1. 数据层改造
- **全局变量管理**: 将写死的地点数组改为全局变量 `currentRouteLocations`
- **策略管理**: 添加 `currentRouteStrategy` 变量管理路线策略
- **动态更新**: 所有地图生成函数都使用这些全局变量

### 2. 界面层改造
- **输入界面**: 在地图区域添加可折叠的路线输入区域
- **用户交互**: 提供起点、途经点、终点和策略选择
- **实时反馈**: 输入验证和加载状态提示

### 3. 功能层改造
- **路线生成**: 根据用户输入动态构建路线配置
- **地图刷新**: 重新调用地图API生成新路线
- **分段更新**: 自动更新所有分段地图

#### 填充当前数据
```javascript
// 填充当前路线数据到输入框
function populateRouteInputs() {
    // 根据当前路线地点数组填充输入框
    const startLocation = document.getElementById('startLocation');
    const waypoint1 = document.getElementById('waypoint1');
    const waypoint2 = document.getElementById('waypoint2');
    const endLocation = document.getElementById('endLocation');
    const routeStrategy = document.getElementById('routeStrategy');

    if (startLocation && currentRouteLocations.length > 0) {
        startLocation.value = currentRouteLocations[0];
    }
    if (waypoint1 && currentRouteLocations.length > 1) {
        waypoint1.value = currentRouteLocations[1];
    }
    if (waypoint2 && currentRouteLocations.length > 2) {
        waypoint2.value = currentRouteLocations[2];
    }
    if (endLocation && currentRouteLocations.length > 0) {
        endLocation.value = currentRouteLocations[currentRouteLocations.length - 1];
    }
    if (routeStrategy) {
        routeStrategy.value = currentRouteStrategy;
    }
}
```

**说明**: 
- 动态填充输入框，支持不同数量的途经点
- 安全地检查元素存在性
- 自动处理起点和终点的映射

#### 生成自定义路线（核心函数）
```javascript
// 生成自定义路线
async function generateCustomRoute() {
    console.log('开始生成自定义路线...');
    
    try {
        // 获取用户输入的地点
        const startLocation = document.getElementById('startLocation').value.trim();
        const waypoint1 = document.getElementById('waypoint1').value.trim();
        const waypoint2 = document.getElementById('waypoint2').value.trim();
        const endLocation = document.getElementById('endLocation').value.trim();
        const routeStrategy = document.getElementById('routeStrategy').value;

        // 验证输入
        if (!startLocation || !endLocation) {
            alert('起点和终点不能为空！');
            return;
        }

        // 构建新的路线地点数组
        const newLocations = [startLocation];
        if (waypoint1) newLocations.push(waypoint1);
        if (waypoint2) newLocations.push(waypoint2);
        newLocations.push(endLocation);

        console.log('新的路线配置:', {
            locations: newLocations,
            strategy: routeStrategy
        });

        // 更新全局路线配置
        currentRouteLocations = newLocations;
        currentRouteStrategy = routeStrategy;

        // 隐藏输入框
        hideRouteInput();

        // 显示加载状态
        showMapLoading();

        // 重新生成地图
        await initMap();

        // 更新页面上的路线显示
        updateRouteDisplay(newLocations);

        console.log('自定义路线生成完成');

    } catch (error) {
        console.error('生成自定义路线失败:', error);
        alert('生成路线失败: ' + error.message);
    }
}
```

**说明**:
1. **输入获取**: 获取所有用户输入的地点信息
2. **输入验证**: 确保起点和终点不为空
3. **数组构建**: 动态构建地点数组，只包含非空的途经点
4. **全局更新**: 更新全局变量，影响所有后续操作
5. **界面更新**: 隐藏输入框，显示加载状态
6. **地图重生成**: 调用 `initMap()` 重新生成地图
7. **页面更新**: 更新页面上的路线显示

## 🔄 工作流程

1. **用户点击"自定义路线"按钮**
   - 调用 `showRouteInputModal()` 显示输入框
   - 自动填充当前路线数据

2. **用户修改路线信息**
   - 在输入框中修改起点、途经点、终点
   - 选择路线策略（驾车/步行/公交）

3. **用户点击"生成路线"按钮**
   - 调用 `generateCustomRoute()` 函数
   - 验证输入数据
   - 构建新的路线数组

4. **更新全局配置**
   - 更新 `currentRouteLocations` 数组
   - 更新 `currentRouteStrategy` 策略

5. **重新生成地图**
   - 调用 `initMap()` 生成主地图
   - 调用 `generateSegmentMaps()` 生成分段地图
   - 更新页面显示
