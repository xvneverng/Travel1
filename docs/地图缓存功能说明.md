# 地图缓存功能使用说明

## 概述
地图缓存功能可以避免重复生成相同路线的地图，显著提升性能。当用户请求相同景点组合的地图时，系统会直接从数据库返回已缓存的地图URL。

## 数据库表结构

### map_cache 表
```sql
CREATE TABLE map_cache (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    cache_key VARCHAR(255) NOT NULL,        -- 缓存键（景点名称用逗号连接）
    map_url TEXT NOT NULL,                  -- 地图URL
    locations TEXT NOT NULL,                -- 景点名称列表
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_cache_key (cache_key),
    UNIQUE KEY uk_cache_key (cache_key)
);
```

## 工作原理

### 1. 缓存键生成
- 将景点名称列表用逗号连接作为缓存键
- 例如：`["南京南站", "中山陵", "夫子庙"]` → `"南京南站,中山陵,夫子庙"`

### 2. 缓存查询流程
```
用户请求地图 → 生成缓存键 → 查询数据库 → 
有缓存？→ 是：返回缓存URL
         → 否：生成新地图 → 保存到缓存 → 返回新URL
```

### 3. 缓存保存
- 地图生成成功后，自动保存到数据库
- 缓存键和地图URL一一对应
- 相同景点组合只保存一次

### 3. 控制器集成 (RouteController.java)
```java
@PostMapping("/map")
public ResponseEntity<MapResponse> generateMap(@RequestBody RouteRequest request) {
    // 1. 先检查缓存
    String cachedMapUrl = mapCacheService.getMapUrl(request.getLocations());
    if (cachedMapUrl != null) {
        return ResponseEntity.ok(MapResponse.success("从缓存获取", cachedMapUrl));
    }
    
    // 2. 缓存中没有，生成新地图
    MapResponse response = routePlanningService.generateMap(request);
    
    if (response.getCode() == 200) {
        // 3. 保存到缓存
        mapCacheService.saveMapUrl(request.getLocations(), response.getData().getMapUrl());
    }
    
    return ResponseEntity.ok(response);
}
```

## 缓存管理

### 查看缓存数据
```sql
-- 查看所有缓存
SELECT * FROM map_cache ORDER BY created_at DESC;

-- 查看特定缓存
SELECT * FROM map_cache WHERE cache_key = '南京南站,中山陵,夫子庙';

-- 统计缓存数量
SELECT COUNT(*) as cache_count FROM map_cache;
```

### 清理缓存
```sql
-- 删除特定缓存
DELETE FROM map_cache WHERE cache_key = '南京南站,中山陵,夫子庙';

-- 清空所有缓存
DELETE FROM map_cache;
```

## 注意事项

### 1. 缓存键规则
- 景点顺序影响缓存键
- `["A", "B", "C"]` 和 `["C", "B", "A"]` 是不同的缓存键
- 建议前端保持景点顺序一致

### 2. 缓存更新
- 地图URL变化时需要手动清理相关缓存
- 建议定期清理过期或无效的缓存

### 3. 存储空间
- 每个缓存记录约占用1-2KB
- 1000个不同景点组合约占用1-2MB
- 可根据需要设置缓存清理策略

## 扩展功能

### 1. 缓存过期机制
```sql
-- 添加过期时间字段
ALTER TABLE map_cache ADD COLUMN expires_at TIMESTAMP;

-- 查询有效缓存
SELECT * FROM map_cache 
WHERE cache_key = ? 
AND (expires_at IS NULL OR expires_at > NOW());
```

### 2. 用户个性化缓存
```sql
-- 添加用户ID字段
ALTER TABLE map_cache ADD COLUMN user_id VARCHAR(50);

-- 用户专属缓存
SELECT * FROM map_cache 
WHERE cache_key = ? AND user_id = ?;
```

### 3. 缓存统计
```sql
-- 缓存命中率统计
SELECT 
    COUNT(*) as total_requests,
    SUM(CASE WHEN cache_hit = 1 THEN 1 ELSE 0 END) as cache_hits,
    AVG(response_time) as avg_response_time
FROM map_requests_log;
```
