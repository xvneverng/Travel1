# 分段地图功能说明

## 🗺️ 功能概述

分段地图功能将完整的旅游路线分解为多个相邻地点之间的路线段，每个路线段都有独立的地图显示，提供更详细的导航信息。

## 🔧 核心功能

### 1. 自动分段生成
- **触发时机**: 主地图生成成功后自动触发
- **分段逻辑**: 将路线按相邻地点对进行分割
- **示例**: `[A, B, C, D]` → `[A→B, B→C, C→D]`

### 2. 动态路线支持
- **支持自定义路线**: 用户输入新路线后自动重新生成分段地图
- **实时更新**: 路线变化时自动清理旧地图并生成新地图

### 3. 智能错误处理
- **API限制检测**: 自动检测并处理API调用频率限制
- **网络错误重试**: 网络错误时自动等待并重试
- **优雅降级**: 部分分段失败时不影响其他分段的生成

### 1. API限制错误
```javascript

    showApiLimitError();
    break; // 停止生成剩余分段地图
}
```

### 2. HTTP 429错误
```javascript
if (response.status === 429) {
    showApiLimitError();
    break;
}
```

### 3. 网络错误重试
```javascript
if (error.message.includes('Failed to fetch')) {
    console.log('🌐 网络错误，等待3秒后继续...');
    await new Promise(resolve => setTimeout(resolve, 3000));
}
```
